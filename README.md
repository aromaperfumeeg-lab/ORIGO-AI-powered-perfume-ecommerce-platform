# ORIGO Storefront

واجهة متجر عطور عربية/إنجليزية مستوحاة مباشرة من الصفحات النهائية في ملف التصميم المرجعي.

## التشغيل

```powershell
npm start
```

ثم افتح `http://127.0.0.1:4173`.

- واجهة المتجر: `http://127.0.0.1:4173/`
- دخول الإدارة: `http://127.0.0.1:4173/admin-login.html`
- لوحة الإدارة: `http://127.0.0.1:4173/admin.html`

## التحقق

```powershell
npm test
```

يدعم المتجر:

- العربية RTL والإنجليزية LTR مع حفظ الاختيار.
- الوضع النهاري والليلي مع حفظ الاختيار.
- بحث ذكي ثنائي اللغة بالاسم والماركة والنوتة مع اقتراحات فورية وسجل بحث حديث.
- فلاتر وفرز متقدم للمنتجات، مفضلة، سلة، واختبار عطر ذكي.
- مكتشف عطر كامل من 8 مراحل بملخص مباشر ونتائج محسوبة حسب التفضيلات والميزانية.
- مكتشف بديل ذكي ببحث واقتراحات فورية ونتائج تشابه وتوفير ومقارنة تفصيلية.
- صور منتجات أصلية مولّدة خصيصًا لخدمة البدائل ومحفوظة داخل المشروع.
- تفاصيل منتج كاملة بالنوتات والمزايا والصور.
- هرم مكونات مرئي ورسومات SVG مصغرة للنوتات، الثبات، الفوحان والموسم.
- منظومة SVG متجهية موحّدة للتنقل والمزايا والمنتجات ولوحة الإدارة، واضحة في الوضعين النهاري والليلي.
- معرض منتج تفاعلي بصور مصغرة للمكونات والأداء وصورة العبوة.
- خط Dubai الحديث للعربية وSegoe UI Variable للإنجليزية.
- مقارنة عطرين مع نسبة توافق وأشرطة أداء.
- مسار دفع من أربع مراحل: السلة، العنوان، الدفع، والتأكيد.
- حساب مستخدم، تسجيل دخول، نقاط مكافآت، سجل طلبات وتتبع مرئي.
- تعديل كميات السلة، كوبون `ORIGO10`، استبدال النقاط وحقول دفع آمنة.
- تقييمات عملاء وملخص تقييم تفصيلي داخل صفحة المنتج.
- لوحة إدارة عربية/إنجليزية للمبيعات والطلبات والمنتجات والمخزون والتحليلات.
- إعدادات إدارة مستقلة لمكتشف العطر ومكتشف البديل ومعايير المطابقة.
- صفحة 404 وصفحة Offline وتهيئة PWA قابلة للتثبيت والعمل الجزئي دون اتصال.
- تخطيط متجاوب لسطح المكتب والجوال.
